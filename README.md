# java-lotto-precourse

## 프로젝트 개요
간단한 로또 발매기 프로그램입니다. 사용자가 로또를 구매하고, 당첨 번호와 비교하여 수익률을 계산하는 기능을 제공합니다.

## 주요 기능 목록

### 1. 로또 구매
* 로또 구입 금액을 입력받는다.
    * 로또 1장의 가격은 **1,000원**이다.
* 입력한 구입 금액만큼 로또를 발행한다. (ex: 5,000원 입력 시 5장)
* 발행한 로또 번호들을 사용자에게 출력한다.
    * 발행한 로또 수량 및 번호를 출력한다.
    * 로또 번호는 오름차순으로 출력한다.
* **[예외]** 구입 금액이 1,000원 단위가 아닐 경우
* **[예외]** 구입 금액이 숫자가 아니거나 1,000원 미만일 경우

### 2. 로또 발행 규칙
* 발행되는 로또 번호의 숫자 범위는 **1 ~ 45**까지이다.
* 발행하는 로또 1개는 **중복되지 않는 6개의 숫자**로 구성된다.

### 3. 당첨 번호 입력
* 당첨 번호 6개를 입력받는다.
    * 당첨 번호는 쉼표(,)를 기준으로 구분한다.
* 보너스 번호 1개를 입력받는다.
* **[예외]** 당첨 번호 또는 보너스 번호가 1~45 범위를 벗어나는 경우
* **[예외]** 당첨 번호 또는 보너스 번호가 숫자가 아닌 경우
* **[예외]** 당첨 번호 6개 간에 중복이 있는 경우
* **[예외]** 당첨 번호와 보너스 번호가 중복되는 경우

### 4. 당첨 결과 및 통계
* 사용자가 구매한 로또와 당첨 번호를 비교하여 당첨 내역을 결정한다.
* 당첨 기준은 다음과 같다.
    * **1등:** 6개 번호 일치 (2,000,000,000원)
    * **2등:** 5개 번호 + 보너스 번호 일치 (30,000,000원)
    * **3등:** 5개 번호 일치 (1,500,000원)
    * **4등:** 4개 번호 일치 (50,000원)
    * **5등:** 3개 번호 일치 (5,000원)
* 당첨 통계(등수별 당첨 개수)를 출력한다.
* 총 구입 금액 대비 총 당첨금의 수익률을 계산하여 출력한다.
    * 수익률은 소수점 둘째 자리에서 반올림한다. (ex. 100.0%, 51.5%, 1,000,000.0%)

## 예외 처리
* 예외 상황 시 에러 문구를 출력해야 한다. 단, 에러 문구는 "[ERROR]"로 시작해야 한다.
* 에러 메시지 출력 후, 해당 부분의 입력을 다시 받는다.
